# 台股加權點數計算機

公開網站：<https://a0979989987-coder.github.io/taiwan-stock-weight-contribution/>

每日盤後解析前十二大權值股對臺灣加權股價指數的估算貢獻。GitHub Pages 提供公開前端；盤後立即更新透過公開後端抓取並驗證官方報表。歷史结果保存在 `data/history.json`；訪客不需要登入或 API 金鑰。

## 更新規則

GitHub Actions 於台北時間平日 13:35、13:40、16:35、16:40 執行。只有在加權指數、十二檔當日收盤、前一交易日收盤及權重資料完整且互相吻合時，才新增當日資料。休市、資料延遲或缺漏時不建立紀錄，也不覆蓋歷史。

可在 Actions 頁面手動執行 `Update close data and deploy`。GitHub 的排程可能延遲數分鐘。

## 計算

`個股估算貢獻點數 = 前一交易日加權指數收盤 × 公布權重 × 個股收盤漲跌幅`

資料來源：臺灣證券交易所每日收盤行情、臺灣期貨交易所成分股暨市值比重。結果為估算值，不是官方精確指數歸因。

## 金融早報

上列「金融早報」提供圖片對應的 22 項行情。GitHub Actions 每天台北時間 08:30（UTC 00:30）抓取一次，寫入 `data/morning.json` 並部署；保留最近 90 天。排程可能因 GitHub 佇列延遲，頁面會顯示實際抓取時間與各列來源報價時間。

美股、亞洲指數、VIX、STOXX 50、外匯、美元指數、BTC 及商品期貨取自 Yahoo Finance；美債 2 年與 10 年殖利率取自美國財政部 XML。商品明確標示為期貨，殖利率每日變動使用基點（bp）。行情漲跌優先使用來源當日比較基準，缺少時採前一交易日收盤，避免期貨換月價差被誤當為單日漲跌；不使用期間起始價格。沒有資料顯示空值；來源失敗可沿用上份資料並標示過期，避免顯示虛構 0%。

「重新讀取」載入已發布的每日快照；盤後計算機的「立即更新」維持原功能。首次與程式發布當天的早報為手動初始化，實際時間另行標示。

驗證：`python -m unittest discover -s tests`、`node tests/morning-ui.cjs`。

## 臺指期夜盤

第一頁額外顯示最近已完成的臺股期貨 TX 近月夜盤：收盤、官方漲跌、最高最低、成交量與夜盤時段。每日 08:30 與金融早報一起從期交所盤後交易行情表更新 `data/night.json`。選最近到期的月契約，排除價差與週契約；休市向前查找最近完成的夜盤，來源失敗時保留舊結果並明確標示。夜盤交易歸屬日可能與開始日期不同，亦獨立於第一頁所選現貨歷史日期。重新讀取會載入已發布快照。
